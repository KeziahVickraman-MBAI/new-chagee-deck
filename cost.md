# Cost and revenue inputs: Chagee storyboard deck

Generated 2026-10-24 from `assumptions.json` and the model outputs. **Do not edit this file by hand**: change `assumptions.json`, then rerun the two commands below, and every number here and in the deck updates together.

```bash
python3 storyboard/build_storyboard.py   # rebuilds the deck and refreshes the model outputs
python3 storyboard/export_costs.py       # rewrites this file
```

Money is **S$ (SGD)**, Singapore as the reference market, unless a line says **A$** (the Australia slides, under things to consider). USD figures approved earlier were converted at 1.2725 SGD per USD (section 5, _meta).

## 1. How to read the status column

| Status | Meaning | Can we quote it as fact? |
|---|---|---|
| sourced (L-…) | From a public document; the source is listed in section 7 | Yes, with the source |
| sourced (press / price check, P-…) | Press article or a price we checked | Yes, as "reported" |
| team or informal source (I-…) | Team research or an anonymised Chagee contact | No: "according to an informal source, to confirm" |
| course material (C-…) | OPIM639 slides | As the course model |
| assumption | Our illustrative input, **not Chagee data** | No: say "we assume" |

Almost every cost is an assumption. Chagee does not publish outlet-level costs, wages, rents or machine prices.

- **status**: APPROVED with changes (Singapore reference market, demand floor 0, machine-speed range to >= 30 s). Monetary assumptions first approved in USD are converted at fx_sgd_per_usd; the approved USD figure is kept as value_usd.
